Put credentials and decisions back at the center of Apassy.

Four-agent audit · Needs work · Proposed flows below are not implemented.

Navigation and reading load

Vault · Requests · Search

The current Vault starts with a directory and status. Credential details repeat unavailable Mac-only sections. Agents gives monitoring a primary destination.

1Unlock to credentials
2Find or add an item
3Use it and return

Remove from the daily path

Healthy sync banners, repeated “unlocked”, unavailable Agent Use / Rules sections, agent statistics.

Keep within reach

Agent Access in Settings and item/request context. Preserve revoke, freshness checks, security issues and sync recovery.

Daily organization and creation

Make saving and cleanup dependable

Switching from paste to manual entry loses the chosen folder. Cleanup is one item at a time. Search and old filters can hide the result of saving.

1Choose Login or Paste
2Enter fields + folder
3See the saved item

Add the missing controls

Multi-select, bulk Move with Undo, Move Folder, clear search scope, and search by email or website.

Keep the strong foundation

Three-column library, batch paste detection, full folder paths and owner checks. Secret Copy needs an explicit product-policy decision.

Attention, routing and outcomes

A notification should lead to useful work

Mac alerts open the app without an event destination. iOS can open the newest request after unrelated vault prompts. “Sent” asks the owner to infer the result.

1Open Requests
2Review and decide
3See confirmed outcome

Quiet by default

Visible requests update without duplicate banners. Suggestions stay nonurgent. Resolved work leaves Waiting and stays in Activity.

Preserve privacy and truth

iOS keeps its generic private push and opens a refreshed list. “Waiting for Mac” stays distinct from confirmed permission or command completion.

Missing interaction

Choose a login beside the field

Inline login suggestions do not exist in the current extension. The toolbar picker is implemented; enabling passkeys does not add password suggestions.

1Focus → matching accounts
2Choose → owner check
3Return to the filled form

Design the recovery too

Distinct unlock/connect/retry states. Bind to the chosen form. Handle username-first login and explicit password updates.

Keep authorization narrow

Opt-in site access, site-scoped metadata, browser-verified origin/frame/document, fresh approval and no automatic submission.

Fix before visual polish

Correctness

Trust

Request lifecycle: preserve context, distinguish sent from confirmed, and reconcile stale alerts on refresh.
