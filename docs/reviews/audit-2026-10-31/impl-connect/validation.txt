Flow
Mac Settings > Devices > Get approvals on your iPhone. No operator code, account,
Stripe or paid sync. A signed Connect request uses a P-256 key committed to the
SQLCipher vault before network writes. The saved key survives restart, offline
failures and a lost response. Legacy 0.5.8 returns a clear retained-key error when
connect_key_used cannot be recovered; the F06 challenge route is feature-detected.
Neither path rotates a key on an ambiguous failure. Retry-After seconds distinguish
short edge limits from capacity limits. Membership has only Questions.

The iPhone opens the same vault from iCloud Drive, scans the pairing code, compares
safety words and waits for Mac confirmation. A QR-only secret encrypts the question
key and public trust rows over the existing opaque relay transport. The iPhone
checks vault/recipient/answer keys and tombstones, then commits the membership and
keys together. It offers Request Notifications and Open Requests. No answer private
key is transferred. Fresh Connect pairing replaces a Keychain key retained after
reinstall. Existing operator-code and paid-sync paths remain available.
