F12d · The help behind ⓘ

Connectors

A connector runs named operations with a credential.

Agents get only the fields it names, never the token.

It works only with credentials for its hosts.

Version 1 reads only. Install needs Touch ID.

  • Rows: name, Bundled tag for app-bundled plugins, subline "<hosts> · <n> operations · <matching item or Installed date>". Bundled rows open a read-only operations page (as F12b, no buttons); installed rows have Remove….
  • Changed file: warning text "The file changed after install. Not loaded." and only Remove…; reinstall goes through Install….
  • Install… (the one primary button) opens the file picker for one .json; a refused manifest shows its first error in the sheet's place, with only Cancel. A new host in a new version needs a new check.
  • Owner check detail lists the hosts and the operation count; the sheet lists the operation titles and the output fields.

Choices made in this mockup

  • Dark values follow macOS dark materials (grouped surfaces lighter than the detail column) and are checked for 4.5:1; three dark text roles are lighter than Apple's defaults to pass on FILL.
  • Six proposed roles (P1–P6) for literals that sit outside kit.rs today; the selected-sidebar count switches to LABEL in both appearances, because SECONDARY fails there (3.74 light).
  • Favorites: a star in the toolbar of the detail, a star in the row meta of other lists, ⌘D (free today). No undo HUD except F4d.
  • Access request detail regrouped into facts, "The Agent Says", and "If You Allow"; Allow Once is the one primary.
  • Turn Off the Bouncer? alert (F3b) added to the existing switch, so the dark sheet has a real use.
  • Frame fill keeps the panel's fixed heading; the five-line detail carries both origins.
  • Watch: the Vault fact goes first; scrolling reaches Folder, Hosts, and the buttons.
  • Connectors live in Tools as the third group, below Command Line and Browser Extension.

Open questions

  • The D2 frame-fill detail runs past 12 words because both origins must be in the trusted text. This mockup keeps it.
  • iPhone buttons: this mockup uses title case for new and renamed buttons, as the owner asked. Older iPhone strings ("Connect this iPhone") stay as they are until M7 touches them. Should they all change now?
  • Watch: when the last vault is forgotten, should the watch go back to setup, as here, or keep an empty This Watch with Connect a Vault?
