# Tailnet spike (iPhone)

Spike only: plan s8 unit T0, ADR 0040. A project of its own that embeds libtailscale, joins the
owner's tailnet, dials the Mac, and measures. It is not a part of the Apassy app.

The build commands, the pins, the owner's device test, and the results table are in
[docs/design/spike-tsnet-ios.md](../../../docs/design/spike-tsnet-ios.md).
